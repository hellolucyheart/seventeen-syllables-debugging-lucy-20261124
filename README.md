**The Breakpoint Holds Still** — one haiku about debugging, three lines in the 5-7-5 syllable shape, seventy-nine characters, written fresh for this bounty:

> The breakpoint holds still
> a log line scrolls past midnight
> and I wrote the bug

The picture at the centre is the halted program: a breakpoint holding the run still while a log line scrolls past midnight. The last line turns it — the hunted bug was the author's own.

`main.py` is its deterministic runner: it writes the haiku to `/output/entry.txt`, byte for byte the same on every run, with no network and no randomness. It validates the haiku first — three lines, 5-7-5 syllables, at most 200 characters.

## Run it

```sh
python3 main.py
```
